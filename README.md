# Последний патрон

Браузерный прототип на Phaser 3, TypeScript и Vite. Первая глава: пять уровней, включая главаря с 6 HP. Сервисы, регистрация и ключи не требуются.

## Открыть без установки

Скачайте `lastshot.html` и откройте его двойным щелчком в настольном браузере. Файл содержит игру целиком, интернет и сервер не нужны. Сохранения локальные; браузеры могут ограничивать хранение для file://, поэтому для постоянного прогресса предпочтительна веб-версия.

Чтобы пересобрать этот файл из исходников: `npm run build:standalone`.

## Запуск

Node.js 22.12+ (в облачной среде проверен Node.js 24).

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Для production-сборки: `npm run build`; файлы находятся в `dist/`. Проверка сборки: `npm run preview`. Для `dist/index.html` нужен HTTP-сервер; отдельный `lastshot.html` открывается напрямую.

## Управление

Клик или касание — выстрел. R или кнопка — перезарядка (1,1 секунды). Esc или кнопка — пауза. Красный платок обозначает бандита, зелёная одежда — мирного жителя. Промах расходует патрон; пропущенный бандит и попадание в жителя отнимают жизнь. У главаря чередуются появление и атака; стрелять можно только при полном проявлении. Попадание прерывает его атаку; если не попасть за время появления, теряется жизнь.

Открытые уровни и рекорды сохраняются локально в браузере. При запрете хранилища доступен прогресс текущей сессии. Сохранение не синхронизируется между устройствами. Звук включается отдельно.

## Проверки

`npm test` — правила прогресса и повреждённые сохранения.

`npx playwright install chromium`, затем `npx playwright test` — браузерное прохождение, перезарядка, сохранение после обновления, мирные жители, босс и мобильное касание. В Linux могут потребоваться системные библиотеки браузера. В этой облачной среде Chromium уже установлен: `CHROMIUM_PATH=/usr/bin/chromium npx playwright test` — загрузка браузера не нужна.

Это прототип с текстурной графикой 2.5D. SDK Яндекс Игр, реклама, облачные сохранения и публикация пока не реализованы. Поезд и логово банды остаются за пределами первой главы.

## Графика и оружие

Графика 2.5D использует детальные текстуры: выветренные доски с волокнами и сучками, металлические обручи и заклёпки, углублённые окна, пыль и направленные солнечные тени. Персонажи получили прорисованные лица, складки ткани, швы и потёртую кожу. Нижний край фигуры скрывается за подоконником.

Встречаются три вида бандитов — усатый стрелок, бородач с патронташем и седой бандит со шрамом — и четыре вида жителей: лавочник в очках, женщина с корзиной, работник ранчо с верёвкой и молодой человек с книгой. Главарь имеет отдельную внешность. Цветовые подсказки сохранены: красный платок у бандитов, зелёная одежда у жителей. Варианты чередуются независимо от игровой случайности; правила и звуки сохранены.

Текстуры встроены в HTML и переиспользуются из одного атласа персонажей. Состав графики описан в [src/visuals/README.md](src/visuals/README.md).

Револьвер и держащая его правая рука используют реалистичную текстуру: потёртая сталь, деревянная рукоять, кожа, пальцы и манжета. Оружие плавно следует за мышью или касанием, слегка покачивается при дыхании. При выстреле видны отдача, мягкая световая вспышка из дула, дым и вращающаяся гильза (аркадный эффект). При перезарядке рука опускается. Пауза замораживает эти эффекты; при новом заходе они очищаются. Все модели встроены в `lastshot.html`, внешние файлы не нужны.

Первый уровень сохраняет бесконечный режим актуальной версии: промах или пропущенный бандит отнимает жизнь; после трёх ошибок сохраняется рекорд и открывается второй уровень. Уровни 2–4 имеют цели, пятый — босс.

После изменения кода выполните `npm run build:standalone` перед `CHROMIUM_PATH=/usr/bin/chromium npx playwright test`: браузерные проверки включают автономный HTML в режиме без сети.

## Главное меню

Закатная улица Дикого Запада, свет фонарей, пыль и перекати-поле оживляют фон. Пять уровней представлены створками салуна: доступные дверцы приоткрываются при наведении и фокусе с клавиатуры, закрытые отмечены замком. При входе в уровень створки распахиваются поверх игровой сцены со звуком скрипа. Управление остаётся доступным мышью, клавиатурой и касанием; на телефоне дверцы выстраиваются в два столбца.

При предпочтении `prefers-reduced-motion` фон остаётся статичным, а переход становится мгновенным. Анимации фона приостанавливаются в скрытой вкладке. Новые изображения встроены в автономный HTML.

## Звук

Кнопка «Звук» включает озвучку и музыку. Главное меню использует полную акустическую кантри-композицию **Corncob — Kevin MacLeod** (около 54 секунд, CC BY 4.0), с банджо и барабанной шаффл-партией. Это запись, а не чиптюн или короткая восьмибитная петля. В меню также есть тихий ветер и скрип дерева; при начале уровня фон останавливается.

При наведении мыши на доступный режим звучит короткий деревянный щелчок. Повторные движения внутри той же кнопки его не дублируют; закрытые уровни молчат. При выборе уровня звучит скрип двух створок салуна.

Выстрел всегда использует **один и тот же сэмпл настоящего Ruger Single Six**, с одинаковыми тоном, громкостью и центральным положением. Он не зависит от цели. Человеческие крики взяты из открытых голосовых записей Flare: бандит при смерти издаёт тот же короткий возглас, что главарь при ранении; житель — тот же возглас на два полутона выше. Звуки ранения и смерти главаря сохранены без изменений.

Выстрел и попадание запускаются одновременно в отдельных каналах. Удар по дереву или крик не заменяет и не приглушает сам звук револьвера. Перезарядка длится 1,1 секунды и приостанавливается вместе с игрой; выключение звука отменяет игровые эффекты. Пустое окно и небо не дают звука дерева.

Все 10 MP3 встроены в один HTML и работают без сети. Источники, исходные контрольные суммы, изменения и лицензии CC0 / CC BY 4.0 / CC BY-SA указаны в [src/audio/CREDITS.md](src/audio/CREDITS.md) и разделе «Звуки и лицензия» внутри игры.
